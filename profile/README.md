## 🧩 The Thing Stack · Thing 系列

We build a family of open-source **“Thing”** tools that span the full arc from devices to intelligence.
我们打造一组开源的 **“Thing”** 工具，贯通「设备 → 边缘 → 智能」的全链路。

<table>
<tr>
<td width="50%" valign="top">

### 🔗 ThingLinks · 云端

[![stars](https://img.shields.io/github/stars/mqttsnet/thinglinks?style=flat-square&label=stars)](https://github.com/mqttsnet/thinglinks)

Enterprise-grade **IoT platform**. MQTT / HTTP / CoAP / TCP / Modbus, rule engine, visual dashboards & multi-tenancy — millions of connections per node.

企业级**物联网平台**：多协议接入、规则引擎、可视化大屏、多租户，单节点百万级连接。

→ **[mqttsnet/thinglinks](https://github.com/mqttsnet/thinglinks)**

### 🛰️ ThingLinks Edge · 边缘 &nbsp;`new`

[![stars](https://img.shields.io/github/stars/mqttsnet/thinglinks-edge?style=flat-square&label=stars)](https://github.com/mqttsnet/thinglinks-edge)

**Edge computing gateway** for on-site deployment — Node-RED multi-instance hosting, built-in reverse proxy, cloud-edge sync with store-and-forward, hardened container runtime. One machine, one `docker compose up`.

**边缘计算网关**：现场单机部署，Node-RED 多实例托管、内置反向代理、云边协同与断网缓存补传、容器运行时加固，一条 `docker compose up` 起服务。

→ **[mqttsnet/thinglinks-edge](https://github.com/mqttsnet/thinglinks-edge)**

## 🧭 Philosophy · 理念

- **Open-source & self-hostable** — 开源、可自托管，数据掌握在你自己手里。
- **Cloud-edge collaboration** — 云端统管，边缘自治；断网时现场照常采集与运行。
- **Built for scale** — 从单节点百万连接的 IoT，到团队级的 AI 知识协作。
- **Developer-first** — 为开发者而造，文档与示例双语友好。
