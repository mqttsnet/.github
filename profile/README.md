## 🧩 The Thing Stack · Thing 系列

We build a family of open-source **“Thing”** tools that span the full arc from devices to intelligence.
我们打造一组开源的 **“Thing”** 工具，贯通「设备 → 智能」的全链路。

<table>
<tr>
<td width="50%" valign="top">

### 🔗 ThingLinks · 物联网

[![stars](https://img.shields.io/github/stars/mqttsnet/thinglinks?style=flat-square&label=stars)](https://github.com/mqttsnet/thinglinks)

Enterprise-grade **IoT platform**. MQTT / HTTP / CoAP / TCP / Modbus, rule engine, visual dashboards & multi-tenancy — millions of connections per node.

企业级**物联网平台**：多协议接入、规则引擎、可视化大屏、多租户，单节点百万级连接。

→ **[mqttsnet/thinglinks](https://github.com/mqttsnet/thinglinks)**

### 🧠 ThingLLM · AI &nbsp;`new`

Cross-tool **AI session & memory manager**. A networked knowledge graph with team governance — sync sessions, memory & skills across Claude Code / Codex / Cursor / Gemini.

跨工具 **AI 会话与记忆管理器**：网状知识图谱 + 团队治理，在各 AI 编程工具间同步会话、记忆与 Skill。

→ **[mqttsnet/thingllm](https://github.com/mqttsnet/thingllm)** · *coming soon*

## 🔌 Ecosystem · 生态

| Repo | What it is |
|---|---|
| [**open-exp-plugin**](https://github.com/mqttsnet/open-exp-plugin) | 插件开发示例 — 展示如何基于 ThingLinks 的 API 与插件架构做自定义扩展 |
| [**bifromq-plugin**](https://github.com/mqttsnet/bifromq-plugin) | BifroMQ 插件库 — 处理 BifroMQ 与物联网业务系统的集成 |
| [**thinglinks-mobile**](https://github.com/mqttsnet/thinglinks-mobile) | 移动端 — uniapp + Wot-UI，支持 H5 / APP / 微信·支付宝小程序 |
| [**thinglinks-multi-tenant-node-red**](https://github.com/mqttsnet/thinglinks-multi-tenant-node-red) | 多租户 Node-RED 环境（Docker） |

## 🧭 Philosophy · 理念

- **Open-source & self-hostable** — 开源、可自托管，数据掌握在你自己手里。
- **Built for scale** — 从单节点百万连接的 IoT，到团队级的 AI 知识协作。
- **Developer-first** — 为开发者而造，文档与示例双语友好。
